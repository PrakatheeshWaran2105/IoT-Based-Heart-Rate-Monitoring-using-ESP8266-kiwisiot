# IoT-Based-Heart-Rate-Monitoring-using-ESP8266-kiwisiot
Monitors heart rate using a pulse sensor connected to the ESP8266 and sends real-time readings to the KiwisIoT platform via Wi-Fi for live monitoring through an IoT dashboard.
IoT-Based Heart Rate Monitoring Using ESP8266 and KiwisIoT

About the Project

The IoT-Based Heart Rate Monitoring System is designed to measure and monitor heart rate using a NodeMCU ESP8266 and a Pulse Sensor. The Pulse Sensor detects heartbeat signals and helps calculate the heart rate in beats per minute (BPM).

The ESP8266 collects the heart rate readings from the sensor and transmits the data over Wi-Fi to the KiwisIoT platform. Users can monitor real-time heart rate readings through the KiwisIoT dashboard, making it easier to observe heartbeat changes remotely.

This project demonstrates how IoT technology can be used for basic heart rate monitoring, real-time health data visualization, and educational healthcare applications.

Note: This project is an educational prototype and is not intended for medical diagnosis or clinical use.
